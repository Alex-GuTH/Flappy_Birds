# Flappy Bird 游戏

这是一个使用 Pygame 实现的经典 Flappy Bird 游戏克隆，并增加了双人对战模式、道具系统和动态难度等新功能，提供了更有趣和挑战性的游戏体验。

## ✨ 功能特性

*   **游戏模式**:
    *   **单人模式**: 挑战自己的最高分，体验经典玩法。
    *   **双人竞技**: 在同一屏幕上与朋友对战，看谁能坚持到最后。
*   **道具系统**:
    *   🛡️ **护盾道具**: 拾取后可抵御一次致命碰撞（管道或边界）。
    *   💰 **双倍得分**: 在限定时间内，每次成功通过管道获得的分数翻倍。
*   **动态难度**: 随着玩家分数的增加，管道的间隙会逐渐变小，游戏挑战性随之提升。
*   **精美界面**:
    *   动态的主菜单和星空背景。
    *   清晰的游戏内 HUD，实时显示分数、存活状态和游戏时间。
    *   丰富的小鸟、管道和道具动画效果。

## 🚀 安装与运行

请确保您的计算机上已安装 **Python 3.8** 或更高版本。

### 1. 获取项目文件

将整个项目文件夹（包含 `main.py` 和其他所有文件）复制到您的电脑上。

### 2. 安装依赖

项目依赖 `pygame` 库。我们已经提供了 `requirements.txt` 文件，您可以使用 pip 快速安装。

建议在虚拟环境中安装，以避免与其他项目产生冲突。

```bash
# 创建并激活虚拟环境 (可选)
python -m venv venv
# Windows
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 3. 运行游戏

安装完所有依赖后，直接运行 `main.py` 文件即可启动游戏：

```bash
python main.py
```

游戏将首先显示主菜单，您可以根据提示选择游戏模式。

## 🎮 操作指南

*   **主菜单**:
    *   使用**鼠标点击**或按键盘上的 **`1`** / **`2`** / **`Q`** 键来选择选项。
*   **游戏中**:
    *   **玩家1**: 按 **`空格键`** (Space) 控制小鸟向上飞。
    *   **玩家2**: 按 **`上箭头键`** (Up Arrow) 控制小鸟向上飞。
    *   **返回菜单**: 按 **`ESC`** 键可以随时退出当前游戏，返回主菜单。
